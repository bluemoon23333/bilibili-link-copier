# B站链接复制（浏览器扩展）

一次点击，把 B 站视频变成「现在就能播的链接」：BV 号、b23 短链、解析站链接，或者测速后最快的 CDN 直链。

> 仓库：<https://github.com/bluemoon23333/bilibili-link-copier>
> 主页：<https://bluemoon23333.github.io/bilibili-link-copier/>
> 隐私政策：<https://bluemoon23333.github.io/bilibili-link-copier/privacy.html>

## 安装

1. 从 [Releases](https://github.com/bluemoon23333/bilibili-link-copier/releases/latest) 下载最新的 zip 并解压；
2. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），开启「开发者模式」；
3. 点「加载解压缩的扩展」，选择解压后含 `manifest.json` 的那一层；
4. 建议固定到工具栏：点拼图图标 → 固定本扩展。

需要 Chromium ≥ 109。从商店安装后无需上面步骤。

## 用法

配置是一个有序列表，每条 = 前缀 + 后面接什么（链接 / BV 号）+ 备注。前两条固定在单击、双击上，第 3 条起才进右键菜单。

| 操作 | 结果 |
| --- | --- |
| 单击图标 | 复制第 1 条 |
| 双击图标（450 ms 内两次） | 复制第 2 条 |
| 右键图标 | 第 3 条起的线路，外加「线路测速…」「设置前缀与备注…」 |
| 视频页右下角「复制链接」按钮 | 和图标一样：单击 / 双击 / 右键 |
| 非 B 站页面、取不到内容 | 不复制，角标变红 |

角标 1.8 秒后消失。鼠标悬停在图标上会显示当前单击、双击分别对应哪条备注。

举例（默认配置）：

| 条目 | 复制出来 |
| --- | --- |
| 第 1 条 `https://api.xuan25.com/bili-resolve/` + 接 BV 号 | `https://api.xuan25.com/bili-resolve/BV1unhJ6JEvE` |
| 第 2 条（空前缀）+ 接 BV 号 | `BV1unhJ6JEvE` |
| 第 3 条「智能最快」 | 测速最快节点的 mp4 直链 |

### 页面上的「复制链接」按钮

打开 B 站视频页、番剧页、列表页或直播间，右下角会出现一个粉色「▶ 复制链接」胶囊按钮，行为与工具栏图标一致：

- 单击 → 第 1 条；450 ms 内点两下 → 第 2 条；
- 右键 → 按钮上方弹出第 3 条起的菜单，末尾是「线路测速…」「设置前缀与备注…」；
- 点空白处或按 Esc 收起菜单；
- 只在上面这些页面出现，首页 / 搜索 / 动态页不会打扰你。

### 支持哪些页面

| 页面 | 复制成什么 |
| --- | --- |
| `www.bilibili.com/video/BV…`（含 `?p=`） | 前缀 + BV 号，或最短链接 |
| `www.bilibili.com/video/av…` | 最短链接 |
| `www.bilibili.com/bangumi/play/ep…` | 番剧页链接 |
| `www.bilibili.com/list/…?bvid=BV…` | 收敛成视频链接 |
| `live.bilibili.com/12345` | `https://live.bilibili.com/12345` |
| `b23.tv/xxxx` | 原短链 |

### 设置页

右键图标 →「设置前缀与备注…」。

- **类型**：接有效链接 / 接 BV 号 / 智能最快节点 / 解析接口（JSON）
- **前缀**：解析站地址，原样拼在内容前面；**留空就只复制 BV 号**，所以不需要单独的「复制 BV 号」菜单项
- **备注**：最多 24 字，会显示在右键菜单和图标提示里
- 最多 20 条，改完自动保存，下面的「效果预览」实时显示单击 / 双击 / 右键会复制什么
- 前缀里可以用 `{url}` / `{bv}` 占位符，把内容插到中间

## 线路测速

设置页的「线路测速」会用测试 BV 号（默认 `BV1AM4y1M71p`）把每条线路跑一遍：解析站回 302 要多久、可能给出哪些 CDN 节点（带出现概率）、每个节点的首包延迟和下载速率，最后用图标评级。

- 只读视频开头几 MB，标准档十几秒完成；
- 结果自动保存，下次打开设置页还能看到，也可以随时重测；
- 第一次点「开始测速」会弹一次「访问网站」权限，允许即可，之后不再问。

「智能最快」条目就吃这份排行：挑最快的节点，同族 `*.bilivideo.com` 直接换 host，其它族去找之前吐出过它的解析站，拿不到就依次退下一名。

## 隐私

不收集任何数据，没有服务器，也没有统计。配置存在浏览器同步存储里，测速结果只留在本机。

权限只在你点击的那一刻生效：`activeTab` / `scripting` 读当前页的 BV 号，`clipboardWrite` 写剪贴板，`contextMenus` 建右键菜单，`storage` 存配置，`offscreen` 在后台写剪贴板。测速另需一次可选权限「访问所有网站」，不给也能正常复制。

详见 [PRIVACY.md](PRIVACY.md)。

## 已知限制

- **最高 720P**：匿名调 B 站接口只给 720P，1080P 及以上要登录 Cookie，换哪条线路都一样。
- 双击窗口固定 450 ms；最多 20 条配置。
- 前缀原样拼接，不做 URL 转义。
- 只在普通网页生效；`chrome://`、扩展页、PDF 阅读器里不工作。
- 解析站偶尔会慢或超时，表里会标 `⚠️` / `⛔`，重测一次通常就恢复。
- 「智能最快」依赖测速结果：没测过会按线路顺序解析一次，效果和普通条目差不多。
- 直播链接只做到「复制标准房间号链接」，它不是视频直链。
